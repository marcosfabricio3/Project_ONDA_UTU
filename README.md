# ONDA – 100th Anniversary Tribute Website

Frontend project developed as a historical tribute to ONDA, a former Uruguayan interdepartmental transport company.  
The website presents a structured visual timeline highlighting key milestones in the company's legacy.

## Live Demo
https://marcosfabricio3.github.io/Project_ONDA_UTU/index.html

---

## Project Overview

This project was built as an academic and portfolio piece focused on:

- Semantic HTML5 structure
- Modular CSS architecture
- Responsive design principles
- Performance optimization
- Clean file organization
- Vanilla JavaScript for interactivity

The goal was to recreate the historical narrative of ONDA in a modern, accessible, and visually structured format.

---

## Tech Stack

- HTML5
- CSS3 (modular architecture)
- JavaScript (ES6)
- Google Fonts (Poppins)

No frameworks were used. The project is fully static.

---

CSS is separated by responsibility:
- Layout
- Components
- Responsive behavior

---

## Key Features

- Historical interactive timeline
- Image lightbox carousel
- Responsive navigation with hamburger menu
- Lazy loading images
- Scroll-based UI interaction
- Clean modular styling structure

---

## Responsive Design

The project adapts to:

- Desktop
- Tablet
- Mobile devices

Media queries are handled in a dedicated responsive stylesheet.

---

## Purpose

This project demonstrates:

- Strong frontend fundamentals
- Clean structure and separation of concerns
- Attention to accessibility and semantics
- Ability to deploy using GitHub Pages
